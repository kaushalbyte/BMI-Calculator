# BMI Calculator 🏋️‍♂️

A simple and responsive Body Mass Index (BMI) Calculator built using HTML, CSS, and JavaScript. This project is part of my web development learning journey.

## Features ✨
- Calculates BMI accurately based on height and weight.
- Rounds off the result to 2 decimal places for clean presentation.
- Simple, user-friendly, and responsive design.

## Technologies Used 🛠️
- **HTML5:** Structure of the web page.
- **CSS3:** Styling and layout.
- **JavaScript:** BMI calculation logic and DOM manipulation.
